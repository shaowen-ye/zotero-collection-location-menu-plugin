# Zotero Collection Location Menu Plugin / Zotero 条目所在文件夹菜单插件

![Collection Location Menu logo](icons/icon-128.png)

Zotero Collection Location Menu 是一个用于查看和整理 Zotero 条目所在 collection / 文件夹位置的独立插件。它面向同一文献条目散布在多个文件夹、需要快速确认位置并清理多余位置的 Zotero 文库。

这个插件处理的是 Zotero collection membership，也就是同一个条目出现在多个 collection 中的“位置关系”。它不会检测或合并多个独立重复文献条目，也不会删除文献条目、附件或笔记。

## 主要功能

### 条目所在文件夹右键菜单

插件会在 Zotero 条目右键菜单中添加 `所在文件夹` 子菜单。选中单个顶层文献条目时，子菜单会列出该条目所在的所有 collection 路径，例如 `项目A / 机制文献 / 禁渔`。

每个文件夹位置下提供常用操作：跳转到该文件夹并重新选中条目、从该文件夹移除此条目、只保留该文件夹位置并移除其他位置。

### 跳转到指定文件夹位置

当一个条目存在于多个文件夹中时，可以从菜单中选择任意路径并跳转。插件会切换 Zotero 左侧 collection，并在条目列表中重新选中原条目。

这适合快速判断同一条目为什么出现在多个项目中，或定位某个条目在 Zotero 文件夹树中的实际位置。

### 单条目位置整理

对于单个条目，插件支持：

- `从此文件夹移除...`：只移除该条目在当前指定文件夹中的位置
- `只保留这个文件夹...`：保留指定位置，移除同一条目的其他文件夹位置
- `从所有文件夹移除...`：让条目变成未归档条目

这些操作只修改条目的 collection 位置，不会删除条目本身，也不会删除附件或笔记。所有修改操作都会二次确认。

### 多选批量管理器

当选中多个顶层文献条目时，右键菜单会显示批量入口：`所在文件夹（批量）：N 项`。批量操作不把所有动作塞进右键菜单，而是打开独立批量管理器。

批量管理器会用表格显示每个条目和它所在的文件夹位置，并汇总涉及的文件夹。你可以勾选条目、选择一个目标文件夹位置，然后执行跳转、批量移除或批量只保留。

### 未归档条目提示

如果条目没有加入任何 collection，菜单会显示 `未加入任何文件夹`。在批量管理器中，未加入任何文件夹的条目也会单独统计，方便识别未归档文献。

## 快速使用

单条目：

1. 在 Zotero 条目列表中右键一个顶层文献条目
2. 打开 `所在文件夹`
3. 选择某个文件夹路径
4. 点击 `跳转到这里`、`从此文件夹移除...` 或 `只保留这个文件夹...`

多条目：

1. 在 Zotero 条目列表中选中多个顶层文献条目
2. 右键并打开 `所在文件夹（批量）：N 项`
3. 点击 `打开批量管理器...`
4. 在管理器中勾选条目并选择文件夹位置
5. 执行 `跳转并选中`、`从选定文件夹移除`、`只保留选定文件夹` 或 `从所有文件夹移除`

## 菜单示例

单条目菜单：

```text
所在文件夹
  📁 项目A / 机制文献 / 禁渔
    跳转到这里
    从此文件夹移除...
    只保留这个文件夹...
  📁 项目B / 参考文献
  从所有文件夹移除...
```

多选菜单：

```text
所在文件夹（批量）：6 项
  批量整理：6 个顶层文献条目
  打开批量管理器...
```

未归档条目：

```text
未加入任何文件夹
```

## 整理规则

### 从指定文件夹移除

只移除条目和指定 collection 之间的位置关系。条目如果还在其他 collection 中，会继续保留那些位置。

### 只保留指定文件夹

把条目的 collection 列表改为只包含指定 collection。这个操作适合清理同一条目出现在多个不再需要的文件夹中的情况。

### 从所有文件夹移除

移除条目的全部 collection 位置，使其成为未归档条目。条目本身仍保留在 Zotero 文库中。

### 批量整理

批量操作只处理勾选的顶层文献条目。附件、笔记、子条目和非普通文献对象会被忽略。

## 行为边界

- 只处理 Zotero 同一条目在多个 collection 中的位置关系
- 不检测多个独立重复条目
- 不合并独立重复文献条目
- 不会把条目移入回收站
- 不会删除附件、笔记或 PDF 文件
- 支持多选批量整理，但只处理顶层文献条目
- 右键纯附件、纯笔记或空白处时不会显示插件菜单
- 混合选择时会自动忽略非顶层文献对象

## 设置说明

当前版本没有单独设置页，核心配置在源码 `collection-location-menu-plugin.js` 的 `config` 中：

- `menuLabel: "所在文件夹"`：单条目右键菜单名称
- `batchMenuLabel: "所在文件夹（批量）"`：多选右键菜单名称
- `collectionLabelPrefix: "📁 "`：文件夹路径前缀
- `revealLabel: "跳转到这里"`：跳转操作名称
- `removeFromCollectionLabel: "从此文件夹移除..."`：从指定文件夹移除
- `keepOnlyCollectionLabel: "只保留这个文件夹..."`：只保留指定文件夹
- `removeAllCollectionsLabel: "从所有文件夹移除..."`：从全部文件夹移除
- `openBatchManagerLabel: "打开批量管理器..."`：批量管理器入口

## Logo

插件内置一个简洁的“文件夹 + 定位针 + 路径点线”图标，用来表达查看条目所在文件夹位置和跳转到目标文件夹的功能。

## 安装

1. 在 Zotero 中打开 `工具 -> 插件`
2. 点击右上角齿轮
3. 选择 `Install Add-on From File...`
4. 选择构建好的 `.xpi`
5. 重启 Zotero

安装文件：

- `dist/zotero-collection-location-menu-plugin-0.4.2.xpi`

## 构建 XPI

在插件目录运行：

```bash
bash build.sh
```

构建产物会出现在：

- `dist/zotero-collection-location-menu-plugin-0.4.2.xpi`

## 兼容性

- Zotero 7、8、9

当前 manifest 明确标记为兼容 Zotero `7.0` 到 `9.*`。
