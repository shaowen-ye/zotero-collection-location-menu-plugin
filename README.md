# Zotero Collection Location Menu Plugin

一个独立的 Zotero 右键菜单插件，用来查看单个条目所在的所有文件夹位置。

## 功能

- 在 Zotero 条目右键菜单中添加 `所在文件夹` 子菜单
- 选中 1 个或多个顶层文献条目时显示
- 子菜单列出该条目所属的所有 collection 路径
- 每个路径下提供 `跳转到这里`、`从此文件夹移除...`、`只保留这个文件夹...`
- 支持 `从所有文件夹移除...`
- 多选时右键菜单只提供 `打开批量管理器...`
- 批量管理器用表格预览条目和所在文件夹，并提供批量跳转、批量移除、批量只保留
- 所有移除/合并操作都会二次确认
- 移除/合并只修改条目的 collection 位置，不删除文献条目、附件或笔记

子菜单示例：

```text
所在文件夹
  📁 项目A / 机制文献 / 禁渔
    跳转到这里
    从此文件夹移除...
    只保留这个文件夹...
  📁 项目B / 参考文献
  从所有文件夹移除...
```

多选时示例：

```text
所在文件夹（批量）：6 项
  批量整理：6 个顶层文献条目
  打开批量管理器...
```

批量管理器中可以勾选条目、选择一个文件夹位置，然后执行：

- `跳转并选中`
- `从选定文件夹移除`
- `只保留选定文件夹`
- `从所有文件夹移除`

未加入任何 collection 的条目会显示禁用项：

```text
未加入任何文件夹
```

## 构建 XPI

在插件目录运行：

```bash
bash build.sh
```

构建产物会出现在：

- `dist/zotero-collection-location-menu-plugin-0.4.0.xpi`

## 安装

1. 在 Zotero 中打开 `工具 -> 插件`
2. 点击右上角齿轮
3. 选择 `Install Add-on From File...`
4. 选择构建好的 `.xpi`

## 兼容性

- Zotero 7

当前 manifest 明确标记为兼容 Zotero `7.0.*`。

## 当前行为说明

- 只处理 Zotero 同一条目在多个 collection 中的显示位置
- 不检测或合并多个独立重复条目
- 不会把条目移入回收站，也不会删除附件或笔记
- 支持多选批量整理，但只处理顶层文献条目
- 多选识别会兼容 Zotero 7 的多种选择接口，并自动忽略非顶层文献对象
- 批量操作在独立弹窗管理器中完成，不再把所有批量动作塞进右键子菜单
- 右键纯附件、纯笔记或空白处时不会显示插件菜单；混合选择会自动忽略非顶层文献对象
